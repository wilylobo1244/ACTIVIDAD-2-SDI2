# 2. DEFINICIÓN DEL MVP

## 2.1 Lean Inception Acelerado

### Visión
SmartSales DSS es el sistema web que ayuda a dueños y gerentes de tiendas minoristas a tomar decisiones comerciales informadas con un panel de control basado en datos.

### Problemática
Actualmente no existe un análisis rápido de qué productos venden mejor y cuáles ocupan inventario sin rotación.

### MVP
Aplicación cliente-servidor con CRUD de productos y ventas, más un dashboard analítico para productos estrella, productos hueso y stock crítico.

### Personas
- Dueño de tienda: requiere visibilidad de los productos más rentables.
- Analista de ventas: necesita métricas claras para proponer acciones.
- Administrador: gestiona el catálogo y controla el stock.

### Lo que es y no es

| ES | NO ES |
|------|------|
| Sistema DSS para ventas minoristas | ERP financiero completo |
| Arquitectura cliente-servidor | Marketplace multi-vendedor |
| CRUD de productos y ventas con dashboard | Sistema de facturación electrónica |
| Análisis de productos y stock | Gestión de nómina |

| HACE | NO HACE |
|------|------|
| Administra catálogo e inventario | Automatiza compras a proveedores |
| Registra ventas y actualiza stock | Maneja pagos online |
| Calcula productos estrella/hueso | Controla contabilidad fiscal |
| Exporta reportes | Administra RRHH |
